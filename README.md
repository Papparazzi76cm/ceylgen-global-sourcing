# Ceylgen Global Sourcing

Quiero que diseñes y desarrolles desde cero una web corporativa B2B, dinámica, tecnológica, multilingüe y completamente responsive para la marca CEYLGEN.



No quiero una tienda online ni venta directa. La web debe funcionar como escaparate internacional de productos, captación de oportunidades comerciales y repositorio de documentación técnica.



La marca es una empresa española dedicada a la importación y comercialización internacional de materias primas y productos naturales premium. Importa principalmente desde Sri Lanka y puede suministrar productos a clientes de España y de cualquier parte del mundo.



La empresa no fabrica. Selecciona proveedores, coordina el suministro, facilita documentación técnica y conecta productos de origen con compradores profesionales.
